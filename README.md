# ovro.ja

OVRO.JA storefront frontend starter.

## Deploy on Cloudflare Pages
1. Create a new Pages project and connect the separate GitHub repository `jovibebd-hub/ovro.ja`.
2. Framework preset: **None**.
3. Build command: leave empty.
4. Build output directory: `/`.
5. Deploy. The site is a static `index.html`.

## Current scope
- Responsive storefront layout, search, category filtering, product cards, product detail dialog and browser-local cart.
- Product prices are intentionally shown as “দাম শীঘ্রই”; no verified OVRO.JA sale prices or stock were supplied.
- Checkout, payments, order storage, admin, shipping, customer reviews, policies and live inventory are not connected yet.
- The “সেরা অফার” section does not invent discounts; it stays in a coming-soon state until verified sale prices are configured.

This repository is separate from JO Vibe.
